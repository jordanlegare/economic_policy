Data governance

Sources & assumptions

Live Bank of Canada observations are refreshed when this page loads. Broader structural variables use the latest documented model baseline when a machine-readable release is unavailable. The status badge clearly identifies fallback operation.

What remains fixed?

Inflation, labour, fiscal, financial, energy, exchange-rate, trade exposure and behavioural parameters are locked. Only the U.S. tariff is editable, ensuring every strategy is compared against the same economic vintage.
