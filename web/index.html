Receipts equal the effective sector-weighted tariff multiplied by the post-elasticity import base. Because bilateral exports for one nation are imports for the other, both deficits reach zero only when the shared bilateral balance reaches zero. Data governance

Sources & assumptions

Live Bank of Canada observations are refreshed when this page loads. Broader structural variables use the latest documented model baseline when a machine-readable release is unavailable. The status badge clearly identifies fallback operation.

What remains fixed?

Inflation, labour, fiscal, financial, energy, exchange-rate, trade exposure and behavioural parameters are locked to the same economic vintage. Negotiators can change headline tariffs, sector coverage and decision preferences; every published revision is then compared against that common baseline.
