# Principal Decision Brief

The principal briefing is a purpose-built senior-official report generated by the Canada-U.S. Diplomatic Policy Studio. It replaces the previous dashboard-oriented PDF export as the default saved briefing while retaining the dependency-free local PDF generator.

## Audience and decision standard

The report is designed for a principal, ministerial/senior-official briefing, or delegation head who needs the current decision in a few minutes rather than a reproduction of the analytical dashboard.

The brief separates:

- recorded negotiating facts from model-inferred counterpart preferences;
- mandate/red-line constraints from analytical thresholds;
- deterministic bargaining results from second-stage uncertainty metrics;
- empirical calibration evidence from model assumptions;
- an economically attractive package from authority to offer it.

## Required sections

Every principal brief contains:

1. Where we are
2. What they want
3. What we want
4. What changed
5. Red lines
6. Best package
7. Bridge package
8. BATNA
9. Key uncertainties
10. Decision required today
11. Recommended language
12. Evidence sources

Delegation notes are appended when locally recorded.

## Package selection

`Best package` is the package selected by the second-stage robust recommendation layer, not simply the first deterministic Pareto package. The report exposes:

- joint probability that both modeled reservation values are cleared;
- Canada and U.S. CVaR10 surplus;
- 95% model surplus intervals;
- maximum regret;
- stability score;
- mandate/authority status.

The `Bridge package` is taken first from the Diplomat Room's mandate-aware Bridge counteroffer, then from the trade-diplomacy bridge package, and finally from the next available Pareto package.

## Counterpart asks

The report only says what the U.S. "wants" when an offer has actually been recorded in the Diplomat Room. If no U.S. package has been recorded, the report explicitly says that model-implied U.S. value must not be described as a stated U.S. ask.

## What changed

The change section draws from the append-only room history and can report:

- a change in the robust recommended package since the latest decision snapshot;
- issue-level movement between the two most recent package offers;
- latest post-round debrief and counterpart signals;
- the current concession/reciprocity balance.

## Decision required today

The decision box is authority-aware. It can distinguish among:

- authorize the robust package inside existing delegation authority;
- seek higher authority for an economically attractive package;
- reject/hold a package that breaches a recorded hard red line;
- use a package only conditionally when it misses the robust joint-clearance gate;
- require reciprocity when Canada is materially ahead in the recorded concession ledger.

## Recommended language

The language section provides an opening, conditional-exchange language, mandate language, analytical-discipline language, and closing/implementation language. It deliberately describes model outputs as estimates under assumptions and does not claim a probability of political acceptance.

## Evidence and provenance

The evidence appendix includes the calibration snapshot ID, completeness/grade, official source registry entries, robustness seed/draw count, and Diplomat Room revision. The footer carries a compact reproducibility fingerprint on each body page.

## Visual design

The generated PDF uses a principal-style cover, restrained Canada-red/navy accents, a decision callout, four key metrics, numbered sections, package cards, BATNA metrics, source rows, and page-level provenance. It uses standard PDF Type 1 fonts (Helvetica family) and remains dependency-free in the browser.

## Security boundary

The brief can include information recorded in the local Diplomat Room. The room/event log and generated local PDF are not an accredited protected/classified records environment. Do not enter or export protected, classified, privileged, or otherwise controlled negotiation material without an approved secure deployment and records architecture.
